Mon Training — version iPhone (PWA)

1. Sauvegarder vos données de la version Mac en JSON.
2. Publier uniquement les fichiers de ce dossier sur un hébergement HTTPS statique (ex. GitHub Pages).
3. Sur iPhone, ouvrir le site avec Safari, Partager > Sur l’écran d’accueil > Ouvrir comme app web.
4. Ouvrir l’application installée, importer la sauvegarde JSON et vérifier les séances.
5. Tester l’enregistrement après fermeture et en mode avion.

IMPORTANT : les données restent dans le stockage local de chaque appareil, elles ne sont pas synchronisées. Ne publiez JAMAIS votre fichier de sauvegarde JSON dans le dépôt public. Les sauvegardes manuelles restent nécessaires.
